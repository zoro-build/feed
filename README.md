# 取阅

**公众号更新，文章主动到你手上。**

订阅公众号，新文章分钟级收录。导出 RSS 放进阅读器，或推送到你的群和系统。

网站：<https://feed.zoro.build>

## 它能做什么

- **订阅** —— 粘贴该公众号任意一篇文章的链接即可添加。不需要登录微信，也不需要你是公众号的运营者。
- **在线阅读** —— 新文章自动汇进时间线，站内直接读排版干净的正文，支持收藏与分组。
- **导出 RSS** —— 汇总 / 分组 / 单个公众号三种带鉴权的订阅地址，输出 RSS、Atom、JSON Feed 三种格式，可导出 OPML；地址可随时重置，旧地址即刻失效。
- **主动推送** —— 有新文章时发一条到钉钉、企业微信、飞书群机器人，或 POST 一段 JSON 到你自己的 Webhook；每条推送的成败 30 天内可查。

## 边界

- 只收公众号群发的文章，发布了但未群发的不会进来。
- 可见范围从你订阅那一刻算起，订阅之前的文章不提供。
- 内容归原作者所有，每篇文章都保留原文链接。
